Define Your Space Curve \mathbf{r}(t)

Function Input Rules:

  • You **must** use the parameter variable t in your expression. This variable runs from 0 to 2\pi.
  • All mathematical functions **must** be prefixed with Math. (e.g., Math.cos(t), Math.sin(t)).
  • Use standard JavaScript syntax for operations (e.g., * for multiplication, ** or Math.pow() for exponents).
  • **Available Constants/Functions:** Math.PI, Math.cos(), Math.sin(), Math.tan(), Math.sqrt(), Math.exp(), Math.log(), etc.

**Example Curve (Figure-Eight):** \mathbf{r}(t) = \left\langle 10 \cos(t), 5 \sin(2t), 5 \sin(t) \right\rangle
